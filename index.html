Editing, for artists

  1. Pick the project. Click a cloud project, or Choose project folder… for files on your computer. Then click the file you want (Amenities, Location…).
  2. Pick a category in the list on the left of the Categories tab. Its details and items appear on the right.
  3. Add a category: click + New category under the list. It starts as a copy of the last category with the names cleared and new ID numbers. Type the name, then fill in its items.
  4. Add a place or amenity: click + Add row under the items table. The new row copies the last one and gets a new ID, so change the name and numbers.
  5. Remove something: click the bin icon. Undo brings it back.
  6. Colors: click the colored square. Icons: pick from the suggestions so the name matches an icon in the app.
  7. Save when you're done. Changed fields are marked in amber until you save.

Map coordinates

In Google Maps, right-click the place and click the two numbers at the top of the menu to copy them. The first is lat, the second is lon.

One-time setup, for the developer

The streamed build runs on Stream Pixel's servers, so it can't read files on an artist's computer. Instead, the data lives in a free public GitHub repository: this editor saves there, and the Unreal app downloads it when it starts.

  1. Create a free public GitHub repository, for example unreal-data. Make a folder per Unreal project inside data/, for example data/Sirrus/, and upload that project's JSON files into it (on GitHub: Add file → Upload files).
  2. Make an access key: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Choose Only select repositories and pick the data repository, then set Contents to Read and write. Give the key to the artists.
  3. In this editor, click Connect cloud and enter the repository name and the key. The projects appear as buttons.
  4. In Unreal, load each JSON from its link instead of the local file. The editor shows the link under the file cards when a cloud file is open. It looks like https://raw.githubusercontent.com/OWNER/unreal-data/main/data/PROJECT/amenities.json.
    • Blueprints: install the free VaRest plugin. On BeginPlay, request the link, then pass Get Response Content as String to the same JSON parsing you use today. Keep the packaged file as a fallback if the request fails.
    • To pick up changes while someone is streaming, repeat the request with Set Timer by Event (every 60 seconds) and refresh the markers.
  5. Package once and upload to Stream Pixel as usual. After that, data changes need no new build. GitHub can take up to about 5 minutes to serve a new save.
  6. Optional: host this editor for free with GitHub Pages. Upload this HTML file to the repository as index.html and turn on Settings → Pages. Artists then open https://OWNER.github.io/unreal-data/.

Field descriptions in this editor are best guesses from the field names. The developer can change them in the FIELD_HELP list near the top of the page's script.
